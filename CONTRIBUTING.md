# Contributing to Rotor Rush

Thanks for helping improve Rotor Rush.

## Development

1. Fork and clone the repository.
2. Install dependencies with `npm install`.
3. Create a focused branch from `main`.
4. Run the game with `npm run dev`.
5. Run `npm run check` before opening a pull request.

## Pull requests

- Keep changes focused and explain the player-facing impact.
- Preserve keyboard and touch controls.
- Avoid adding large dependencies or unoptimized media.
- Include before-and-after performance evidence for rendering changes.
- Confirm the game works in a current Chromium, Firefox, or Safari browser.

## Assets

Only submit assets you created or have permission to redistribute. Optimize raster assets before committing them and document their source in the pull request.
